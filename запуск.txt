============================================
  БОТ ДАРИНЫ — Воронка с тестом
============================================

УСТАНОВКА:
----------
1. Установите Python 3.10+
2. Перейдите в папку бота:
   cd "бот дарины"
3. Установите зависимости:
   pip install -r requirements.txt

ЗАПУСК:
-------
   python bot.py

НАСТРОЙКА:
----------
Все настройки в файле config.py:

1. BOT_TOKEN — укажите токен в файле .env: BOT_TOKEN=ваш_токен
2. CHANNEL_USERNAME — канал для проверки подписки (darina_v_smisle)
3. ADMIN_ID — ваш Telegram ID (для получения уведомлений и статистики)
   Узнать свой ID: напишите боту @userinfobot
4. ADMIN_CONTACT — контакт администратора (@Dana_lavanda)

ДОБАВЛЕНИЕ ВИДЕО:
-----------------
Способ 1 (через бота):
  1. Отправьте видео боту (от имени администратора)
  2. Бот покажет file_id видео
  3. Ответьте на видео командой:
     /setvideo welcome       — приветственное видео
     /setvideo result_a      — подкаст для Типа 1
     /setvideo result_b      — подкаст для Типа 2
     /setvideo result_c      — подкаст для Типа 3
     /setvideo result_d      — подкаст для Типа 4
     /setvideo consultation  — видео-приглашение на консультацию
  * Видео сохраняется в базе и доступно после перезапуска.

Способ 2 (через config.py):
  1. Отправьте видео боту, скопируйте file_id
  2. Вставьте в config.py:
     WELCOME_VIDEO = 'ваш_file_id'
     VIDEO_RESULT_A = 'ваш_file_id'
     и т.д.

КАК ЭТО РАБОТАЕТ:
------------------
1. Пользователь жмёт /start → видит приветственное видео
2. Жмёт «Пройти тест» → 10 вопросов с кнопками A/B/C/D
3. После теста → должен подписаться на @darina_v_smisle
4. Бот проверяет подписку → выдаёт результат теста + видео-подкаст
5. Типы 1-3: предлагает бесплатный интенсив (Да/Нет)
   - Да → направляет к @Dana_lavanda
   - Нет → серия вопросов для понимания причины + повторное предложение
6. Тип 4: приглашает на бесплатную 40-мин консультацию → @Dana_lavanda

КОМАНДЫ АДМИНИСТРАТОРА:
-----------------------
/stats     — статистика: сколько прошли тест, какие типы, конверсия в интенсив
/setvideo  — установить видео (ответом на видео-сообщение)

ВАЖНО:
------
- Бот должен быть администратором канала @darina_v_smisle для проверки подписки
- Установите ADMIN_ID в config.py, чтобы получать уведомления
- Без видео бот работает нормально — просто отправляет текст
